## autonomy-metric-ptma

# PTMA — Autonomy Scoring

> First metric to measure **how independently** AI agents operate

---

## Formula

**PTMA = SAS / (1 + PDR + COF)**

| Term | Meaning |
|------|---------|
| SAS | Self-Adaptation Score |
| PDR | Prompt-Dependency Ratio |
| COF | Correction Overhead |

Score range:
- **1.0** → fully autonomous
- **0.5** → semi-autonomous
- **0.0** → behaves like scripts

---

## Benchmark Highlights (4 Public Datasets)

| Dataset | PTMA | Corrections | Result |
|--------|------|-------------|-------|
| Titanic | **1.0** | 0 | Fully autonomous |
| Diabetes | 0.54 | Few | Some human-like fixes |
| Cancer | 1.0 | 0 | Stable |
| Malignant Cancer | 0.54 | Few | Needs adaptation |

Agents learn & improve across runs.
